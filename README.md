# Amazon Sales Dashboard (Excel)

## Project Overview

This project is an interactive Excel dashboard analysing sales performance using a retail sales dataset.

The goal was to clean messy sales data, build PivotTable-based analysis, and create an interactive dashboard for business reporting.

![Dashboard Preview](dashboard-preview.png)

---

## Tools Used

- Microsoft Excel
- PivotTables
- Pivot Charts
- Slicers
- KPI Cards
- Excel Formulas

---

## Key Metrics

- Total Revenue
- Total Profit
- Profit Margin %
- Total Orders
- Total Quantity Sold

---

## Dashboard Features

- Filter by Region
- Filter by Product Category
- Filter by Year
- Filter by Order Status
- Top 10 Customers by Revenue
- Revenue by Region
- Monthly Revenue Trend
- Revenue by Category

---

## Data Cleaning Performed

- Removed duplicate records
- Standardised inconsistent category names
- Cleaned text fields
- Handled missing values
- Created calculated fields:
  - Revenue
  - Cost
  - Profit
  - Profit Margin

---

## Key Insights

- North region generated the highest revenue
- Technology was the highest-performing category
- Revenue was concentrated among top customers
- Overall profit margin achieved: 26.7%
